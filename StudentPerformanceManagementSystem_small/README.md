# TaskFlow Pro

A premium task management app built with:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express.js
- Database: MongoDB with in-memory fallback for demo mode

## Run
1. `npm install`
2. `node server.js`
3. Open `http://localhost:3000`

The app includes:
- User registration/login/logout
- JWT authentication
- Create, edit, delete, complete, prioritize, and due-date tasks
- Search and filters
- Dashboard metrics and premium responsive UI
